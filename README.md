# 撮影条件シューティング（仮称）

放射線技師教育ゲームシリーズ 第 1 作。一般撮影の撮影条件（管電圧・mAs・撮影距離）をシューティングゲームで覚える。
仕様は [docs/SPEC.md](docs/SPEC.md) を正とする。

## ブラウザ版（スマホで遊ぶ試作）

`main` に push すると GitHub Actions がブラウザ版をビルドし、GitHub Pages に公開する（`.github/workflows/pages.yml`）。

- スマホは **横向き** で遊ぶ。敵をタップしてロックオン、▲▼ で条件を合わせ、曝射パネルを長押し → READY で離して曝射。
- 記録はその端末のブラウザ（localStorage）にだけ残る。
- 条件はダミーのサンプルマスタ。正解は「撮影条件マスタ」画面か、MISS の吹き出しで確認する。

## 開発

```bash
npm install
npm run dev        # Electron で起動（Vite の開発サーバー＋Electron ウィンドウ）
npm run dev:web    # ブラウザだけで起動（保存先は localStorage）
npm test           # ユニットテスト（Vitest）
npm run typecheck
npm run build      # Windows インストーラを release/ に作る（release/ExposureShooter-Setup-<版>.exe）
```

## 構成

| 場所 | 中身 |
|---|---|
| `electron/` | main（ウィンドウ・electron-store）と preload（ストレージ IPC） |
| `src/core/storage/` | `StorageAdapter` と実装（Electron / localStorage / メモリ） |
| `src/core/data/` | zod による行単位の検証 |
| `src/games/exposure-shooter/logic/` | マスタのスキーマ、mAs 系列、撮影距離の選択肢（純粋関数・テスト対象） |
| `src/games/exposure-shooter/scenes/` | Phaser シーン |
| `src/games/exposure-shooter/ui/` | React の画面 |
| `src/app/` | 画面遷移とタイトル |
| `data/conditions.sample.json` | 開発用ダミーマスタ（**条件値はダミー**） |

保存データ（Electron 版）は `%APPDATA%\撮影条件シューティング\radtech-series.json` に入る。

## 動作確認の手順

### フェーズ 1（基盤）

1. `npm test` が全件通る。
2. `npm run dev` で Electron ウィンドウが開き、タイトル画面が出る。
3. 「撮影条件マスタ」を押すと、サンプルマスタ 15 行が分類順に表示される。
   - 右側の mAs 系列に、標準系列にない `7`（膝関節 側面のダミー値）が黄色で追加されている。
   - 撮影距離の選択肢が `100 / 150 / 180 cm` で、最も多い `100 cm` に枠が付いている。
4. アプリを終了して起動し直し、マスタ画面の件数表示から「（サンプル）」が消えている（保存済みのマスタを読み込んでいる）。
5. タイトルの「あそぶ」→ モード選択の右上「撮影条件マスタ」でも同じ一覧を開ける（フェーズ 3 以降）。

### フェーズ 2（コアループ）

1. `npm test` が全件通る（判定・スコア・曝射スイッチ・ダイヤル・出現のテスト）。
2. 「あそぶ」→「スタンダード」→「胸腹部」を押す。奥から敵（部位名と方向を書いた札）が近づいてくる。
3. 敵にカーソルを重ねると黄色の枠でロックオンされ、右パネルに部位・方向・体位・接近までの秒数が出る（敵は常にゆっくり動く。速さは設定の「敵の速さ」）。
   - カーソルを下の操作パネルへ動かしてもロックオンは外れない。Tab で近い敵へ切り替わる。
4. kV・mAs・撮影距離のパネルにカーソルを乗せるとそのパネルが光り、ホイールで値が変わる。右クリックで光るパネルが kV → mAs → 撮影距離 と切り替わる。キーボードは W/S・A/D・Q/E。
5. 左クリック（または Space）を押し続けると準備ゲージが溜まり、「READY」で離すと曝射する。
   - 準備完了前に離すと「準備未完了」と出て曝射しない。
   - READY のまま 5 秒離さないと「管球負荷」と出て準備が解除され、その後離しても曝射しない。
6. マスタ画面で正解の条件を見て合わせて撃つと「PERFECT」、許容範囲内なら「GOOD」で撃破、スコアが増える。
7. 外すと敵が消え、「あなた」と「正解」の条件、ずれの方向、解説を並べた吹き出しが出る。ライフが 1 減る。
8. 放置して敵を防衛ライン（赤い線）に到達させるとライフが減る。ライフが 0 でゲームオーバー、150 秒たてばステージクリア。
9. 終了すると CLEAR / GAME OVER が出て、結果画面に移る（フェーズ 3 の手順を参照）。

### フェーズ 3（画面とモード）

1. `npm test` が全件通る（モード・ランクのテストを含む）。
2. タイトルの「あそぶ」でモード選択が出る。難易度（ビギナー / スタンダード / ハード）を選べる。初回は「復習」が押せない。
3. 「スタンダード」→ ステージ選択に 6 ステージが並ぶ。マスタに撮影がないステージは押せない。
4. 胸腹部を遊ぶ。上段に残り時間・ライフ・スコア・コンボ倍率が出る。150 秒たつと CLEAR、ライフが尽きると GAME OVER が出て結果画面に移る。
5. 結果画面にランク（S / A / B / C）、スコア、撃破数、最高コンボ、被ばく過多と、外した部位の復習リスト（自分の条件・正解・判定・解説）が出る。ベストを更新すると「ベスト更新」が出る。
6. 「外した部位だけ再挑戦」で、外した部位だけが 1 体ずつ出る復習モードになる。上段は「残り N 体」。全員を片付けると CLEAR。
7. 「ステージ選択」に戻ると、遊んだステージに BEST スコアと（クリアしていれば）CLEAR が付いている。
8. モード選択の「ハード（無制限）」で全部位がランダムに最大 5 体出る。上段は経過時間。ライフが尽きるまで続き、結果画面には撃破数・到達時間・最高コンボが出る。モード選択のハードのカードにベストが出る。
9. 結果画面の「もう一度」で同じモード・ステージを最初から遊べる。プレイ中の「やめる」でステージ選択（ハード・復習はモード選択）に戻る。

### フェーズ 4（キャラ）

キャラの見立ては [docs/characters.md](docs/characters.md)、全キャラの一覧は [docs/キャラ一覧.png](docs/キャラ一覧.png)。サンプルマスタの 15 撮影すべてにキャラがある。

1. どのステージを遊んでも、敵がキャラの絵で出る。絵の上に部位名と方向が出る。SVG がない撮影（取り込んだマスタの新しい部位など）は、部位名と方向を書いた札で出る。
2. ロックオンすると驚いた顔（ロックオンの表情）に変わり、外れると元の顔に戻る。撃破するとにっこりした顔を一瞬見せて消える。
3. モード選択の「キャラ図鑑」で全撮影が並ぶ。絵を押すと 接近中 → ロックオン → 撃破 の順に表情が変わる。正解条件と解説も出る。
4. 「撃破済みだけ」にすると、まだ撃破していない撮影は影になり、名前と条件が「？？？」で隠れる。プレイを最後まで終えると、撃破した撮影が図鑑に記録される。

### フェーズ 5（マスタと履歴）

1. `npm test` が全件通る（取り込みの列推測・値の変換、ランキング、学習履歴の集計、設定のテストを含む）。
2. モード選択の右上でプロフィールを追加・切り替え・削除できる（タイトル画面にもある）。
3. 「撮影条件マスタ」→「条件表を取り込む」で施設の Excel / CSV / JSON を選ぶ。
   - 表の上にタイトル行があっても、見出しの行が自動で選ばれる。列の対応も見出しから推測される（違えば選び直す）。
   - 取り込めない行は行番号と理由が一覧に出て、取り込まれない。標準系列にない mAs は「追加される値」に出る。
   - 「置き換える」か「追加する」を選んで取り込む。取り込んだ条件でそのまま遊べる。
4. マスタエディタの表で直接編集・行の追加・削除ができる。エラーの行は赤くなり、直すまで保存できない。CSV / JSON で書き出せる（書き出した CSV はそのまま取り込める）。
5. ハードかスタンダードを最後まで遊ぶと、結果画面に「NEW RECORD!」と順位付きのランキングが出る。名前はその場で直せる。
6. プロフィールを切り替えてもう一度遊ぶと、「ハイスコア」画面で 2 人の記録が並ぶ（1〜3 位は金・銀・銅）。ステージ選択には各ステージの 1 位が出る。
7. 「学習履歴」で、今のプロフィールの撮影ごとの正答率・平均撃破時間と、苦手な撮影が見られる。CSV / JSON で書き出せる。
8. 「設定」で許容値・スロー・準備時間・kV 刻み・MISS 吹き出しの時間・中ボタン・キー割り当て・音量を変えられ、次のプレイから効く。ランキングのリセット（全部 / 表ごと）は確認のあとに実行される。
9. タイトル画面で 15 秒触らないと、ランキングが順に表示される。

### フェーズ 6（仕上げ）

1. `npm run build` で `release/ExposureShooter-Setup-0.9.0.exe` ができる。
2. ダブルクリックするとインストールされ（管理者権限は不要、ユーザーごと）、デスクトップとスタートメニューに「撮影条件シューティング」ができて、アプリが起動する。
   - 署名していないので、「Windows によって PC が保護されました」と出たら「詳細情報」→「実行」。
   - 入る場所は `%LOCALAPPDATA%Programsexposure-shooter`。記録は `%APPDATA%撮影条件シューティング` に残る（アンインストールしても消えない）。
   - アンインストールは Windows の「設定」→「アプリ」から。
3. タイトル →「あそぶ」→ 遊ぶ。効果音が鳴る：準備中のうなり（回転上昇音）、準備完了の音、曝射の「ピー」、PERFECT / GOOD / MISS、防衛ライン到達、管球負荷の警告、ダイヤルのカチッ、ステージクリア / ゲームオーバー。
4. 演出：開始の「START!」、撃破の火花、5 コンボごとの表示、MISS の赤いフラッシュ、READY の曝射パネルが光る、照準の枠が脈打つ、ライフが残り 1 のときハートが脈打つ。
5. 設定の「効果音の音量」で音量を変えられる（0% で無音）。
