# 敵キャラの見立て（SPEC 8）

SPEC 8.2 のスタイルガイドに沿って、撮影 1 つにつき 1 キャラを SVG で作る。
ファイルは `src/games/exposure-shooter/characters/{character}.svg`、表情は `face-approach`（接近中）・`face-lockon`（ロックオン・曝射中）・`face-defeated`（撃破）の 3 つ。

共通の作り：

- X 線フィルムに見立てた角丸の黒い札（`#0f1826`）に、軟部組織（`#7f93a8`）と骨（`#e8eef4`、不透明度で濃淡）を描き、構造を顔のパーツに見立てる。
- 表情は 3 つでそろえる。
  - **接近中**：ふつうの顔。
  - **ロックオン**：目を見開いて口が「o」。汗を 1 滴。
  - **撃破**：目を閉じてにっこり（「きれいに撮れた！」）。キラキラを付ける。
- 正面像は両目、側面像は片目で前方（腹側）を向く。このゲームでは **前方を画面の左** にそろえる。
- R / L マーカーを必ず入れる（白の枠と文字）。
