# 撮影条件シューティング 仕様書（v0.1）

> 放射線技師教育ゲームシリーズ 第1作
> 新人診療放射線技師が **一般撮影の撮影条件（管電圧・mAs・撮影距離）** を、ゲームを通して体で覚えるための奥スクロール型シューティングゲーム。

このドキュメントは Claude Code への実装指示書です。実装時は本書を正とし、記載のない判断が必要な場合は「13. 未決事項」に追記したうえで、最も単純な実装を選んでください。

---

## 1. コンセプト

- プレイヤーは **新人放射線技師**。武器は **放射線発生装置**。
- 奥から迫ってくる敵は **撮影部位を模したキャラクター**（例：胸部正面の「レンちゃん」）。
- 敵ごとに正しい撮影条件を装置に設定し、**実機と同じ二段操作（準備→曝射）** で撃つと撃破できる。
- **1 体につき撃てるのは 1 回だけ。** 正解でも不正解でも、撃った敵はその場で消える。外したときはその場で正解条件を見せ、「間違えた直後に正解を知る」ことを学習の中心にする。
- **快適さを最優先する**。操作のストレスで「条件を覚える」という目的がぶれないようにする。

### シリーズとしての前提
- 今後、別テーマ（CT・MRI・ポジショニングなど）の教育ゲームを同じ基盤で作る。
- スコア記録・設定・データ読み込み・学習履歴は **シリーズ共通基盤（core）** として、ゲーム本体から分離して実装する。

## 2. 技術スタック

| 項目 | 採用 |
|---|---|
| 配布形態 | デスクトップアプリ（インストール形式）。将来 PWA 化する |
| アプリ枠 | Electron |
| UI | React + TypeScript + Vite |
| ゲーム描画 | Phaser 3（React 内にマウント） |
| 状態管理 | Zustand |
| スキーマ検証 | zod |
| Excel / CSV 読み込み | SheetJS (xlsx) |
| 永続化 | ローカルのみ（後述のストレージ抽象層経由） |
| ビルド・配布 | electron-builder（Windows インストーラを主、macOS は任意） |

- **Supabase などの外部バックエンドは使わない。** ネットワーク通信なしで完結させる。
- **PWA 化を見据え、ストレージは抽象化する。**
  - `StorageAdapter` インターフェース（`get` / `set` / `remove` / `list`）を core に定義する。
  - Electron 版は `electron-store` 実装、PWA 版は IndexedDB 実装（v1 では未実装でよい）。
  - ゲーム本体のコードから `electron` / `fs` を直接触らない。触る場合は preload 経由の IPC にまとめる。

## 4. 撮影条件マスタ

### 4.1 スキーマ

条件はアプリにハードコードしない。施設ごとに差し替えられる JSON をマスタとし、アプリ内のエディタで編集・入出力できるようにする。

| フィールド | 型 | 必須 | 説明 | 例 |
|---|---|---|---|---|
| `id` | string | ○ | 一意 ID（英小文字とアンダースコア） | `knee_lat` |
| `region` | enum | ○ | ステージ振り分け用の大分類 | `lower_limb` |
| `part` | string | ○ | 部位 | 膝関節 |
| `view` | string | ○ | 方向・撮影法 | 側面 |
| `position` | string | | 体位 | 側臥位 |
| `kv` | number | ○ | 管電圧 [kV] | 60 |
| `mas` | number | ○ | mAs 値（標準系列のいずれか） | 5 |
| `sid` | number | ○ | 撮影距離 [cm] | 100 |
| `grid` | boolean | | グリッドの有無（**データとして保持するだけで、判定には使わない**） | false |
| `frequency` | `high` / `mid` / `low` | ○ | 撮影頻度。出現率と難度の振り分けに使う | high |
| `character` | string | ○ | 敵キャラ SVG の ID | `knee_lat` |
| `tip` | string | | 外したときと復習画面に出す一言解説 | |
| `kv_tol` | number | | 許容値の個別上書き（±kV） | |
| `mas_tol_steps` | number | | 許容値の個別上書き（±段） | |

`region` の値：`chest_abdomen` / `spine` / `upper_limb` / `lower_limb` / `head_neck` / `pelvis_hip`

### 4.2 mAs 標準系列

mAs は自由入力にせず、次の系列をステップ送りで選ぶ（R'10 系列）。

```
0.5, 0.63, 0.8, 1, 1.25, 1.6, 2, 2.5, 3.2, 4, 5, 6.3, 8, 10, 12.5, 16, 20, 25, 32, 40, 50, 63, 80, 100, 125, 160, 200
```

- 上の系列を既定値とする。
- **マスタに系列にない mAs 値があれば、その値を系列に自動で追加する**（丸めない）。追加した値は昇順に並べ直し、インポート結果の画面に「追加された mAs 値」として一覧で表示する。
- マスタを差し替えたり行を削除したりしたときは、系列を既定値＋現在のマスタにある値で作り直す。

### 4.3 撮影距離

- **選択肢は固定値にせず、マスタの `sid` 列にある値から自動で作る**（重複を除いて昇順）。施設によって基準距離が 100 cm だったり 120 cm だったりするため。
- 初期選択値は、マスタで最も多く使われている `sid` とする。
- マスタが空のとき（初回起動時など）だけ、仮の選択肢 `100 / 150 / 180` を使う。

### 4.4 許容値（難易度ごとの共通値）

| 難易度 | kV 許容 | mAs 許容 | SID |
|---|---|---|---|
| ビギナー | ±5 kV | ±1 段 | 完全一致 |
| スタンダード | ±5 kV | ±1 段 | 完全一致 |
| ハード | ±2 kV | ±0 段 | 完全一致 |

- 行に `kv_tol` / `mas_tol_steps` があればそちらを優先する。
- 数値はすべて設定画面で変更できるようにする。

### 4.5 インポート / エクスポート
- **インポート**：`.xlsx` / `.csv` / `.json`。列名の対応付け画面（列マッピング）を用意し、zod で検証してエラー行を一覧表示する。
- **エクスポート**：`.json` と `.csv`。勉強会での配布や他院との共有に使う。
- アプリ内に **マスタエディタ** を用意し、表形式で行の追加・編集・削除ができるようにする。

### 4.6 開発用ダミーデータ
- `data/conditions.sample.json` に 10〜15 行程度のダミー行を入れる。各 region から 2 行以上。
- **条件値は明らかにダミーと分かる値にし、`tip` に「ダミー」と書く。** 実際の撮影条件を推測して埋めないこと。正式な値は施設の条件表をインポートして使う。

## 6. ゲームモード

### 6.1 スタンダードモード
- **1 ステージ 2〜3 分**のライトな構成。勉強会の合間や休憩中に 1 本遊べる長さにする。
- ステージは region 単位：胸腹部 → 脊椎 → 上肢 → 下肢 → 頭頸部 → 骨盤・股関節。
- 各ステージの敵は、その region の `high` / `mid` を中心に、終盤に `low` を 1〜2 体混ぜる。
- 制限時間内にライフが残っていればクリア。

### 6.2 ハードモード（無制限）
- **全 region の敵がランダムに出現する** エンドレスモード。
- ライフが 0 になるまで続き、時間経過で出現間隔が短くなり、`low` の出現率が上がる。
- 許容値はハード設定（4.4）を使う。
- 記録は「撃破数」「到達時間」「最高コンボ」。

### 6.3 復習モード（結果画面から起動）
- 直前のプレイで外した部位だけを出現させる短いステージ。

## 7. ゲームプレイ仕様

### 7.1 画面と敵の動き
- 疑似 3D の奥スクロール。消失点に向かって収束する床グリッドを流し、前進している感覚を出す。
- 敵は奥（消失点付近）で小さく出現し、拡大しながら手前へ迫ってくる。
- 敵が手前の防衛ラインに到達すると **ライフ -1**。その敵は消える（未撃破として記録）。
- 同時に画面に出る敵は、スタンダードで最大 3 体、ハードで最大 5 体とする。

### 7.2 ロックオン
- 左クリックは曝射に使うため、ロックオンは **マウスカーソルを敵に重ねる（ホバー）** だけで行う。`Tab` キーで最も近い敵へ切り替えることもできる。
- 準備（7.4）を始めた時点でロックオン対象を固定し、曝射が終わるまでカーソルが外れても対象は変えない。
- ロックオン中の敵の情報（部位・方向・体位・接近までの残り時間）を右パネルに表示する。
- **ロックオン中は時間の流れが遅くなる**（スロー）。倍率は難易度で変える（既定：ビギナー 0.35、スタンダード 0.5、ハード 0.8）。
- 敵の部位名・方向・体位は **全難易度で表示する**。ゲームの焦点は「部位を見分けること」ではなく「条件を覚えること」に置く。

### 7.3 条件の設定

**3 つのパラメータの変更はすべてマウスホイールで行う。** 照準（ホバー）と曝射（左クリック）でマウスを使っているので、手をキーボードに移さずに済むようにする。

- **ホイール回転**：選択中のパラメータの値を 1 刻み上下させる。
- **パネルへのホバー**：カーソルが kV・mAs・撮影距離のいずれかのパネル上にあるときは、そのパラメータが選択される。カーソルがパネルから離れても、選択は最後にホバーしたパラメータのまま残す。
- **右クリック**：選択中のパラメータを切り替える（kV → mAs → 撮影距離 → kV …）。照準を敵に合わせたまま切り替えたいときに使う。
- 選択中のパネルは枠を光らせてはっきり示す。
- カーソルを操作パネルへ動かしても、ロックオン中の敵は解除しない。ロックオンが変わるのは、別の敵にカーソルを重ねたときと `Tab` を押したときだけとする。
- 中ボタン（ホイールクリック）にも同じ切り替えを割り当てられるようにする（設定で選択）。

| パラメータ | 1 刻み |
|---|---|
| 管電圧 kV | 既定 5 kV（設定で 1 / 2 / 5 から選択） |
| mAs | 系列（4.2）で 1 段 |
| 撮影距離 | 選択肢（4.3）で 1 つ |

- 値は上下の端で止める（ループさせない）。
- **前回の設定値を保持する。** 敵が変わっても値はリセットしない。
- 補助として、キーボード操作（kV：`W` / `S`、mAs：`A` / `D`、撮影距離：`Q` / `E`）も用意する。キー割り当ては設定画面で変更できる。

### 7.4 曝射（実機の二段スイッチを再現）
デスクトップ版の初期設定は **「左クリック長押しで準備（ロートアップ）、離すと曝射」** とする。

1. **準備（ロートアップ）**：左クリックを押し続ける。準備ゲージが溜まり、回転上昇音が鳴る。
   - 準備時間の既定値は 1.0 秒（設定で 0.5〜2.0 秒）。
   - 準備完了で表示が「READY」に変わり、完了音が鳴る。
2. **曝射**：準備完了後に左クリックを **離す** と曝射する。
   - 準備完了前に離した場合は曝射せず、準備をキャンセルする（「準備未完了」と短く表示）。
   - 曝射すると「ピー」という曝射音とフラッシュが出て、照射のエフェクトが敵に届く。
3. **準備の長時間保持**（任意機能）：準備完了から 5 秒以上離さないと「管球負荷」の警告を出し、準備を自動で解除する。その後に離しても曝射しない。

- キーボードでは `Space` に同じ動作（長押しで準備、離すと曝射）を割り当てる。
- 操作方式は設定で切り替えられるようにしておく（例：「長押し→離して曝射」と「長押し中に別ボタンで曝射」）。将来の PWA 版でのタッチ操作にも使う。

### 7.5 判定
3 つのパラメータすべてが許容範囲内なら撃破。

| 結果 | 条件 | 演出 |
|---|---|---|
| PERFECT | kV・mAs・SID が完全一致 | 撃破、ボーナス |
| GOOD | すべて許容範囲内 | 撃破 |
| MISS | どれかが範囲外 | 敵は消える。ライフ -1。正解条件とずれの方向を表示する |

- **撃ち直しはできない。** 曝射した時点で、結果にかかわらずその敵は消える（撃破時は撃破の表情、MISS 時は別の消え方の演出にする）。
- 曝射後はロックオンを解除する。

**MISS 時の表示**
- 消えた敵の位置から吹き出しを出し、**「あなたの条件」と「正解条件」を並べて** 2.5 秒ほど表示する。ゲームは止めない。
- 吹き出しには、下のずれの方向と `tip` を添える。
- 表示時間は設定で変更できるようにする。

**ずれの方向**（該当するものはすべて表示する）

| ずれ | 表示 |
|---|---|
| kV 高すぎ | kV 高すぎ → コントラスト低下 |
| kV 低すぎ | kV 低すぎ → 透過不足 |
| mAs 不足 | mAs 不足 → ノイズ増加 |
| mAs 過剰 | mAs 過剰 → 被ばく過多 |
| SID 誤り | 撮影距離が違う → 拡大率・線量が変わる |

- 線量が過剰になる方向のミス（kV 高すぎ、mAs 過剰）は **「被ばく過多」カウンタ** に加算し、結果画面に出す。
- MISS はゲーム内で「再撮影」として扱い、ライフを 1 減らす。ビギナー難易度だけは MISS でライフを減らさない（防衛ラインへの到達では減る）。

### 7.6 スコア
- PERFECT 300 点、GOOD 100 点。
- コンボ倍率：連続撃破ごとに ×1 から ×0.5 ずつ上がり、上限 ×4。MISS かライフ減少でリセット。
- 早撃ちボーナス：敵の残り接近時間に応じて最大 +50%。
- 数値はすべて定数ファイルにまとめ、調整しやすくする。

### 7.7 ライフ
- ビギナーは 4、スタンダードは 5、ハードは 3。
- ライフが減るのは「MISS（ビギナー以外）」と「敵が防衛ラインに到達」の 2 つ。
- 数値はステージを遊びながら調整する（未決事項）。

## 8. 敵キャラクター

### 8.1 方針
- キャラは **SVG** で作る。外部の画像素材は使わない。
- 1 撮影（`id`）につき 1 キャラ。ファイルは `src/games/exposure-shooter/characters/{character}.svg`。
- 表情は 3 種類：`approach`（接近中）、`lockon`（ロックオン・曝射中）、`defeated`（撃破）。1 ファイル内に `<g id="face-approach">` などのグループで持たせ、表示を切り替える。
- SVG がないキャラは、部位名と方向を書いた仮のプレースホルダーを自動で表示する。

### 8.2 スタイルガイド
基準キャラは **胸部正面の「レンちゃん」**（`docs/reference/renchan.png`）。全キャラをこの絵柄に揃える。

**配色**

| 用途 | 色 |
|---|---|
| 背景（X 線の黒） | `#0f1826` |
| 軟部組織のシルエット | `#7f93a8` |
| 骨 | `#e8eef4`（不透明度で濃淡を出す） |
| ほっぺ | `#c96b7b` |
| マーカー（R / L） | `#ffffff` の枠線と文字 |
| 狙う骨の強調（小部位用） | `#f5c56a` の点線 |

**顔の作り方のルール**
1. **解剖学的構造を顔のパーツに見立てる。** 例：肺野 → 目、鎖骨 → 眉、横隔膜 → 口元、心陰影 → ハート。
2. **正面像は両目、側面像は片目で前方（腹側）を向く。** 向きの判別がゲームの核なので、このルールは崩さない。
3. **小さい部位（舟状骨・歯突起・踵骨など）は、骨そのものに顔を付けて主役にする。** 周囲の骨は顔のない脇役にし、主役は点線の輪で示す。
4. **目は背景と反転色にする。** 暗い肺野の上なら白目、骨や軟部の上なら黒目にハイライトを付ける。
5. **R / L マーカーを必ず入れ、左右の解剖を正しく描く。** 心陰影は患者の左側、母指の位置などを正しくする。
6. **撮影体位をポーズで表す。** 例：胸部側面は両腕挙上（バンザイ）、舟状骨は尺屈。
7. 線は太めで丸く（`stroke-linecap: round`）、細部は描き込みすぎない。小さく表示されても判別できることを優先する。

**キャラ別の見立て（試作済みの例）**

| 撮影 | 見立て |
|---|---|
| 胸部正面 | 肺野＝両目、鎖骨＝眉、心陰影＝ハート、横隔膜＝口元、気管＝頭頂の通り道 |
| 胸部側面 | 前方の肺野＝片目、両腕挙上、胸椎＝背中側、心陰影＝前下方のハート、L マーカー |
| 膝関節 側面 | 膝蓋骨＝片目（黒目）、関節裂隙＝にっこり口、大腿四頭筋腱＝眉、腓骨＝後方にうっすら |
| 手 正面 | 中手骨の間＝両目（黒目）、指骨＝ツンツン頭、手根骨＝あご、母指の位置で左右 |
| 舟状骨 | 舟状骨そのものが顔、尺屈ポーズ、他の手根骨は顔なし、点線の輪で強調 |

### 8.3 制作の進め方
- 条件マスタの全 `character` について、上のルールに従って SVG を作る。
- region ごとにまとめて作り、作ったら一覧で確認できる **キャラ図鑑画面**（開発用・本番でも閲覧可）に並べる。
- 見立てに迷う部位は、作る前に `docs/characters.md` に見立て案を書いて確認を取る。

### 9.1 プレイ画面（HUD）
- **上段**：ステージ名・モード・残り時間（左）、ライフ（中央）、スコア・コンボ（右）。
- **中央**：奥スクロールの床、敵、ロックオン枠、MISS フィードバックの吹き出し。
- **右**：ロックオン中の敵の情報パネル（部位・方向・体位・接近までの残り時間）。
- **下段の操作パネル**（左から）：kV、mAs、撮影距離、曝射スイッチ（①準備ゲージ、②曝射）。
  - kV・mAs・撮影距離のパネルは、どれもホイールで回すダイヤルとして見せ、前後の値を小さく表示する。
  - ホイールの操作対象になっているパネルは枠を光らせる。
- 画面の基準解像度は 1280×800。ウィンドウサイズに合わせて拡大縮小する。

### 9.2 結果・復習画面
- ステージ名、スコア、撃破数、ランク（S / A / B / C）、被ばく過多の回数。
- **復習リスト（必須）**：外した部位と未撃破の部位を、「部位・方向／自分の条件／正解／判定（kV 過大など）／`tip`」の表で表示する。
- ボタン：ステージ選択、外した部位だけ再挑戦、もう一度。

## 10. 学習履歴

- プレイごとに、敵 1 体ごとの記録（`id`、結果、入力した条件、MISS 回数、撃破までの時間）を保存する。
- 部位ごとの正答率と平均撃破時間を集計し、苦手部位を表示する。
- 成績を JSON / CSV で書き出せるようにする。
- ユーザーはローカルのプロフィール切り替え（名前だけ、パスワードなし）で複数人に対応する。勉強会で 1 台を回して使う場面を想定している。

### 10.1 ハイスコアランキング（アーケード風）
- **同じアプリ（同じ PC）内のプロフィールだけで競う**ローカルランキング。通信はしない。
- ランキングは「モード × ステージ × 難易度」ごとに分け、それぞれ **上位 10 件** を残す。ハードモード（無制限）は難易度ごとに 1 つ。
- 同じプロフィールが複数の順位に入ってもよい（アーケードと同じ）。
- 各記録に残す項目：順位、名前、スコア、撃破数、正答率、最高コンボ、日付。ハードモードは到達時間も残す。

**表示**
- 結果画面でランクインしたら「NEW RECORD」の演出を出し、順位をハイライトしたランキング表を表示する。名前は現在のプロフィール名を自動で入れる（その場で変更もできる）。
- タイトル画面で一定時間操作がないと、アーケードのデモ画面のようにランキング表を順に切り替えて表示する。
- ステージ選択画面には、各ステージの 1 位のスコアと名前を表示する。
- 見た目はアーケードのハイスコア画面を意識する（等幅の数字、1〜3 位を金・銀・銅で強調、行が順に表示されるアニメーション）。

**管理**
- 設定画面から、ランキングのリセット（全体、またはランキングごと）ができる。実行前に確認を出す。
- プロフィールを削除しても、ランキングの記録は名前ごと残す。

### フェーズ 2 で仮に決めたこと（遊びながら見直す）
値はすべて `src/games/exposure-shooter/logic/constants.ts` にある。
- [ ] ステージの長さ 150 秒。制限時間は **実時間** で数え、ロックオン中のスローの影響を受けない（スローで遅くなるのは敵の接近・出現・床の流れだけ）。準備ゲージと MISS の吹き出しも実時間。
- [ ] 敵の接近時間 10 秒、出現間隔 3.2 秒（どちらもゲーム内時間）。終盤 30% で low を 1〜2 体混ぜる。
- [ ] 敵の見かけの大きさは時間に比例して大きくする（奥行きを一定速度で縮めると最後の一瞬で急に大きくなり、読みにくいため）。
- [ ] kV ダイヤルの範囲は 40〜150 kV、初期値 70 kV。mAs の初期値は系列で 10 に最も近い値。
- [ ] ロックオンしていないときは準備を始めない（「敵にカーソルを重ねてロックオン」と表示）。準備中に対象が防衛ラインを越えたら準備を解除する。
- [ ] 中ボタンでのパラメータ切り替えは既定で有効。

### フェーズ 3 で仮に決めたこと
- [ ] ランクの閾値：S は撃破率 90% 以上かつ PERFECT 率 60% 以上、A は撃破率 80% 以上、B は 60% 以上、それ以外は C。ゲームオーバーは C（`constants.ts` の `RANK`）。
- [ ] 7.1 の「スタンダードで最大 3 体、ハードで最大 5 体」はモード（6.1 / 6.2）のことと読んだ。復習モードは 2 体まで。
- [ ] ハードモードは難易度も選べる。許容値は常にハード、ライフ・スロー倍率・MISS でライフが減るかは選んだ難易度に従う（ランキングを難易度ごとに分ける 10.1 と合わせるため）。
- [ ] ハードモードの出現間隔は 3.0 秒から経過 1 秒ごとに 0.015 秒縮め、下限 1.2 秒。low の重みは 0.5 から 1 分ごとに +1、上限 3（high 3・mid 2 に対して）。
- [ ] 復習モードは外した部位（MISS と未撃破）を 1 体ずつ外した順に出し、全員を片付けたらクリア。制限時間はなし。復習の結果はベスト記録に残さない。
- [ ] ステージ選択のベストスコアとクリア状況は、フェーズ 5 のランキングができるまで簡易の記録（`exposure-shooter/best`）に保存する。
